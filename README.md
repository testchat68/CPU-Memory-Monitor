# CPU-Memory-Monitor

Simple CPU and Memory usage monitor for Linux.

Please see the picture: CPU-Memory-Monitor.jpg

## How to install & run

1. Cut/Paste the file `cpu_mem_monitor.py` into your HOME folder.

2. Right-click on the file → Properties → Permissions  
   and check all Execute boxes.

3. Cut/Paste the file `cpu-mem-monitor.desktop` onto your Desktop.

4. Right-click on the `.desktop` file → Properties → Permissions  
   and check all Execute boxes.

That's it — now you can use the program.

## What it does

The program shows real-time information about:

- Current CPU usage (%)
- Current Memory (RAM) usage (%)
- Used / Total Memory

The values are updated automatically.
